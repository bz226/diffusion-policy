# Analysis implementation contract

The analyzer reads the three approved new runs and the original three seeds of each reference method. It never samples a policy, restarts a run, substitutes a later DPPO rerun, or edits a reference result. `--interim --target-itr 70` caps every displayed curve and the progress table at the same iteration; `--final` additionally requires complete worker records, all 140 rows, five checkpoints, clean child-process exit and the merged passed gate record.

An update consumes one fresh 80-episode batch, independently of the number of AdamW steps. Reward coordinates count updates before each rollout; a training result's native environment-step counter includes that rollout's newly collected batch. Evaluation iteration 130 is update 117. The last ten training updates are iterations 129 and 131–139. Each seed's discounted-return gain subtracts its own iteration-1 `J_disc_train`; an old report's shared pretrained-policy anchor is not reused.

Distance curves pair rollout J with `theta_dist_before_update`, or the previous training row's post-update distance. If only checkpoint parameters exist, distance is computed in float64 relative to that run's `state_0`, and only an exactly matching rollout may be plotted. Original DPPO and without_PPO did not log training J, so their checkpoint distances cannot supply the missing vertical coordinate. They are absent from the distance display and J columns, with that limitation stated explicitly.

Figures contain seed-0 values first, and separate three-seed means, with filled-circle markers and no uncertainty bands. Tables retain the individual seeds and mean ± sample SD (ddof=1). Ordinary contrasts use pooled SD `sqrt((s_A²+s_B²)/2)`. The four-condition interaction uses `sqrt((s_DPPO²+s_without_PPO²+s_without_GAE²+s_without_PPO_and_GAE²)/2)`, treating its two reuse contrasts as independent; no paired-seed covariance is assumed. Differences below twice the pooled SD are unresolved.

DPPO's original console log supplies per-minibatch approximate KL, which is averaged within each iteration before averaging iterations. It cannot supply clipfrac or switched-off fraction. Approximate KL remains separate from the unclamped coordinate-summed post-update true-KL diagnostic. New-run PPO step lists supply the within-iteration means of clipfrac, switched-off fraction and approximate KL, retaining any actual early stop. Missing historical diagnostics remain “not logged.”

Timestamped candidates preserve every analysis invocation. Final publishing copies only this study's approved report, tables and five figure pairs; no curated output is created. Completion bookkeeping updates this study's record and inserts its methods/folder links in the completed-experiment checklist only after final verification succeeds.
