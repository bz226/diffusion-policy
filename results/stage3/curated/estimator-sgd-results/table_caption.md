# Table definitions

`seed_results.csv` contains one row for each of the 15 completed condition/seed runs; `condition_results.csv` retains those seed values and their mean and sample SD (ddof=1). Eval endpoints use iterations 0 and 130 (0 and 9.36M training environment steps), while train and discounted returns average each seed's last ten training iterations, 129 and 131–139. Discounted return uses raw decision rewards and gamma=0.99; saturation, out-of-range actions and zero-update fractions summarize all 126 training iterations. Each seed's KL is its median over training iterations; the condition summary averages these three medians, rather than pooling iterations.

`comparisons.csv` applies the specified descriptive rule: a difference smaller than twice the pooled seed SD is unresolved; this is not a significance test. `noise_windows.csv` retains all nonoverlapping ten-iteration windows, each with nine training iterations, including undefined estimates when the summed split dot is nonpositive. Median noise scales in the seed/condition tables use only defined positive-denominator windows, whose counts are also reported; shared coefficients make these approximate diagnostics. `all_runs_long.csv` contains all 2,100 native iteration records without smoothing or filtering, and `summary.json` includes the six prior-reference runs used for comparison.

The five-condition comparison is interim: final-checkpoint evaluations are unavailable and have not been substituted with iteration-130 values. Phase-1 bootstrap confidence intervals are not used in these tables. Exact input paths and the reproduction command are in [the analysis record](../../runs/completed_five_analysis/analysis_record.json).
