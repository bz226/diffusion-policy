# Addendum C methods

## Estimators and controls

This protocol implements the user's Stage-3 Addendum C. All policies begin at the same pretrained actor, with the existing HalfCheetah config, 40 environments, 500 decisions per iteration, four environment steps per decision and ten differentiated denoising transitions. Eighty complete episodes contribute to each training batch. No actor reuse, ratio/log-probability clipping, KL stopping or Gaussian-noise truncation is introduced. COMMON retains score loss and Stage-3 diagnostics. SGD has zero momentum/weight decay and constant learning rate. Evals occur at iterations 0,10,…,130; final checkpoint evaluation covers the actor after the last update.

SGDC computes raw reward-to-go G with gamma = 0.99 and baseline b=cV(s), using the critic values already computed before any critic step. The scalar c=sqrt(reward_scaler.ret_rms.var+epsilon) is copied at iteration start, before the current rollout updates scaler statistics. The configured reward_scale_const is 1. Compute G−cV in float64, then cast to the existing actor dtype and multiply by gamma^k. Denoising weights are 1, log probabilities sum 24 coordinates, and normalization is off. Critic targets, optimizer, epochs and scaling are unchanged. The start-of-iteration critic/scaler are independent of the current sample conditional on state; their approximation quality changes variance but not the score estimator's mean.

SGDC3/SGDC10 use eta = 3 or 10 times the existing E2 calibration eta*=0.00012107235674859004. SGDC3w uses 3 eta* and restores only critic weights and all scaler statistics from the existing frozen_P0.pt; neither actor nor actor_ft is restored by this flag. All optimizer states start as before.

SGDG retains E0's scaled-reward GAE(lambda = 0.95), critic, mean coordinate log probability, denoising discount 0.99 and per-50,000-pair shuffled-chunk advantage normalization. It changes only the actor optimizer and learning rate. calG, seed 3001, freezes the warmed critic/scaler and actor, collects five fresh training batches, and calibrates the actual chunk-normalized gradient with recorded permutations. It uses KL*=0.000584517336086918, the same 20,000-pair trial subset and prescribed decade bracketing/quadratic prediction/at-most-one log-log correction as Stage 3. Restore the actor after every trial. Report exponents, spread and warnings without tuning. The normalized SGDG gradient has no universal eta/2500 conversion into paper units.

## Baseline diagnostics and comparisons

Diagnostics use cached raw rewards, pre-update values and c, with float64 calculations and no RNG, gradients or optimizer changes. Retain per-k mean and population std across 80 episodes for both residuals, plus bin summaries for k=0–49,50–99,100–149,150–199,200–249. Weighted residual energy is the episode mean of sum gamma^(2k)*(G−b)^2, both overall and within each bin; report critic/LOO ratios. Preserve per-k statistics to distinguish variation across episodes from variation across time-to-go.

Use Stage 3 reference results without rerunning them. Per-condition tables give seed values and mean±sample SD(ddof = 1). Differences smaller than twice pooled seed SD remain unresolved, with no additional significance tests. Plot all prescribed Stage 3 trajectories plus residual energies, matched-step KL ratios, early/late split trace 20 × split_diff_sq and critic explained variance. The requested windows use training observations whose iteration labels lie in 1–10,60–70,130–140; evaluation-only and nonexistent iteration 140 rows are excluded. Cold-start comparisons use the first 20 actual actor updates. Final checkpoint evaluations use seed 5000, 80 complete episodes under each sampler and the existing pretrained reference measurements.

## Gates, provenance and execution

C1 checks float64 MC−cV explicitly to relative 1e−12 and discount order. C2 checks the critic and divisor actually used on a live batch against iteration-start snapshots before any scaler/critic mutation. C3 verifies exact critic/scaler restoration and unchanged actors. C4 compares a CPU full update with baseline_diag on/off bitwise, including parameters, optimizer and global RNG states. C5 replays default and NC4 computations against the imported code on CPU/GPU with the Stage 3 equality rules. A failure stops before calibration or production.

The new study source is an ordinary export under the isolated parent worktree's results/stage3_critic/dppo. No nested repository is created inside the study. Runtime outputs live in the main workspace at results/stage3/critic; selected records are copied as ordinary files into the C worktree before committing. The active G branch, source, queue and outputs remain untouched. Reuse Stage 1 Python 3.8/MuJoCo/data/environment settings and absolute paths. Every job explicitly closes its vector environment and checks all workers, retaining failures and nonzero exits. Gate hashes are limited to the user-requested critic/scaler/actor invariants; ordinary revision/source records supply other provenance.

All five conditions have seeds 0, 1, 2 with 140 iterations and checkpoint frequency 35. CalG starts first, SGDC cohorts follow independently of its numeric eta_G result, and SGDG waits for calibration completion. Each cohort runs seeds in parallel on three dedicated GPUs once it fits while preserving G priority. Non-finite training stops that run and marks collapse; other seeds/conditions continue. No retries, altered batches or rescue hyperparameters are authorized. The approved 60 GPU-hour cap and individual wall limits are in approval.json; reaching a resource limit pauses admissions and produces a partial report. Candidate analysis artifacts remain uncurated.

The durable scheduler controller uses one CPU, 2 GiB, no GPU and a 48-hour cap. Its dependency replaces the expiring interactive job before it admits calG, keeping nine G jobs plus the G bootstrap, C controller and calibration within twelve scheduler entries. C training still waits for G to terminate.
